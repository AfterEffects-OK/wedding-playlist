# 披露宴BGM 印刷用プレイリスト作成アプリ

iTunesからエクスポートしたテキストファイルをドラッグ＆ドロップするだけで、結婚式・披露宴のBGM進行表（兼 印刷用プレイリスト）を簡単に作成・編集できるローカルWebアプリケーションです。

## 主な機能

- **ファイルドラッグ＆ドロップ対応**:
  - **メインBGM用**: iTunesから書き出したテキスト（`.txt` / `.csv`）をドロップして自動読み込み。ファイル名から日付（例: `1011` → 10月11日）を自動抽出。
  - **迎賓・お見送り用**: 専用エリアへのドロップで、ファイル名や内容を自動判別してメモ欄へ反映。
- **柔軟なシーン・再生指示の選択**:
  - 各楽曲に対して「入場」「乾杯」「歓談」などのシーンや、「頭から」「サビから」といった再生指示を選択可能。
  - 8文字以上の長いシーン名は自動で文字幅が75%に縮小され、きれいに収まります。
  - よくあるシーンの切り替わりタイミングで**自動的に空白行を挿入**し、見やすく整理。
- **歓談曲・自由メモ欄**:
  - 左側に備え付けられたメモ欄に、自由なテキストや歓談曲のリストを記入可能。印刷時にも自動で枠内に収まるようサイズ調整されます。
- **直感的な操作（ドラッグ＆ドロップ並び替え）**:
  - 曲順の入れ替えがドラッグ＆ドロップで簡単に行えます。また、手動での「➕空白行」の挿入や「削除」も可能。
- **こだわりの印刷デザイン（A4横向き1ページ）**:
  - 開始日時（月・日・時間）や、新郎新婦のお名前（「様」の文字サイズ調整を含む）を綺麗に配置。
  - 余白やレイアウトを最適化し、A4横向き1枚にすっきりと収まる印刷プレビューに対応。

## 使い方

1. **アプリの起動**:
   - `index.html` をお使いのWebブラウザ（Google Chrome, Edge, Safariなど）で開きます。
2. **ファイルの読み込み**:
   - 「メインBGM用プレイリスト」のエリアに、iTunesのエクスポートファイルをドラッグ＆ドロップします。
   - 必要に応じて「迎賓・お見送り用プレイリスト」のファイルも追加します。
3. **情報の入力と調整**:
   - 開始日、開始時間、新郎新婦のフルネームを入力・確認します。
   - 各曲のシーンや再生指示、曲順（ドラッグで入れ替え）を調整します。
4. **印刷する**:
   - 画面右上（またはコントロール内）の **「このリストを印刷する (横向き)」** ボタンをクリックし、印刷プレビューを確認して印刷します。

## 動作環境

- モダンなWebブラウザ（Chrome, Safari, Edgeなど）
- 追加のインストールやサーバー設定は不要です。ファイルをブラウザで開くだけですぐにご利用いただけます。
