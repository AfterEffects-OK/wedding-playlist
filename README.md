# 🎵 iTunes プレイリスト印刷ツール Pro

結婚式・披露宴の音響スタッフやプランナー向けに特化した、**iTunes/Apple Musicの書き出しテキスト（.txt）からA4横向きのプロ仕様BGM指示書を簡単・美しく作成できるWebアプリケーション**です。

ドラッグ＆ドロップ操作や直感的なモーダル編集により、複雑な手間をかけずに完璧なタイムスケジュール付きBGMリストを構築できます。

---

## ✨ 主な特徴

1. **ファイル自動解析＆メタデータ抽出**
   - ファイル名やエクスポートされたテキストデータから、挙式日・新郎新婦名・プレイリストの内容を自動で読み取ります。
2. **迎賓・送賓（お見送り）用プレイリストの自動統合**
   - メインBGMファイルに加え、「迎賓」や「お見送り」のファイルも個別にドラッグ＆ドロップで読み込み可能。表の最上部・最下部に自動で「（プレイリストあり）」行を挿入します。
3. **シーンごとのグループ分け＆自動空白行**
   - シーンを変更すると、演出の区切り（迎賓、中座、再入場、おひらき等）に応じて自動的に適切な空白行が挿入され、見やすいレイアウトを維持します。
4. **自由自在な再生指示の組み合わせ（順番設定付き）**
   - 「頭から」「サビから」「フェードアウト」などの基本指示や、「時間指定（例: `0'16"～オープン`）」を、クリックした順に**複数かつ任意の順番で**組み合わせることができます。
5. **A4横向き 1枚最適化の印刷出力**
   - 長い曲名やアーティスト名も自動で幅がスケーリングされ、印刷時に綺麗に収まるよう自動調整されます。

## 🚀 使い方

### 1. ツールの起動
- `index.html` ファイルをブラウザ（Google Chrome、Safari、Edgeなど）で直接開くだけで動作します。サーバーへのアップロード等は不要です。

### 2. iTunesからのデータ書き出し方法
1. iTunes（またはApple Music App）でプレイリストを選択します。
2. メニューの **[ファイル] ＞ [ライブラリ] ＞ [プレイリストを書き出す...]** を選択し、テキストファイル（`.txt`）形式で保存します。

### 3. ファイルの読み込み
- **📝 迎賓・お見送り用ファイルエリア**：ファイル名に「迎賓」や「お見送り（送賓）」を含むテキストファイルをドロップします。
- **♫ メインBGM用ファイルエリア**：iTunesから書き出したメインのプレイリストテキストファイルをドロップします。

### 4. 編集と調整
- **シーン選択**: 各行のプルダウンから「入場」「乾杯」「歓談」などのシーンを選びます（自由入力も可能）。
- **曲名・アーティスト名**: 直接テキストボックスをクリックして修正・テキストの範囲選択が可能です。
- **再生指示の編集**: 曲名の下にあるプルダウンから「時間指定 / 複数選択...」を選ぶと、専用のモーダルウィンドウが開き、クリック順に指示を自由に組み合わせられます。
- **行の並び替え**: 各行の左側にあるハンドル（`☰`）をドラッグ＆ドロップして順番を入れ替えられます。
- **メモ欄**: 左側の「その他プレイリスト・メモ欄」に自由にテキストを入力すると、印刷プレビューにも自動反映されます。

### 5. 印刷する
- 画面上部の **「🖨️ A4横向きで印刷する」** ボタンをクリックするか、ブラウザの印刷機能（`Ctrl + P` または `Cmd + P`）を使用し、**印刷向きを「横（Landscape）」**に設定して印刷してください。
